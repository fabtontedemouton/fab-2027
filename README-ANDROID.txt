FAB' MATRIX 2027 — Android APK

Ce dossier ajoute une véritable application Android (APK) qui embarque la version web en local.
Elle n'a pas besoin d'Internet pour afficher l'interface et utiliser les fonctions locales.

Pour construire l'APK :
1. Ajouter le contenu de ce pack à la racine du dépôt fab-2027 en conservant les dossiers.
2. Sur GitHub, ouvrir Actions.
3. Lancer "Build FAB MATRIX Android APK" avec Run workflow, ou attendre le lancement automatique après commit.
4. Quand le workflow est vert, ouvrir son exécution et télécharger l'artefact FAB-MATRIX-2027-APK.
5. Extraire le ZIP de l'artefact puis installer app-debug.apk sur Android.

C'est un APK debug non signé pour distribution Play Store. Android peut demander d'autoriser l'installation depuis cette source.
Les données sont stockées localement dans l'application ; export CSV recommandé pour sauvegarde.
