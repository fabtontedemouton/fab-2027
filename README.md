# FAB' MATRIX 2027

Application légère de suivi de saison de tonte et de préparation hors saison.

## Fonctionnalités
- Compteur journalier et cumul vers l'objectif de 25 000 moutons
- Total de la semaine, record journalier et historique
- État physique et qualité de tonte
- Export CSV de l'historique
- Hors saison : 3 séances hebdomadaires et 4 habitudes d'équilibre alimentaire
- Sauvegarde locale sur le téléphone (localStorage)
- PWA installable et utilisable hors ligne après le premier chargement

## Mise en ligne
Déposer tous les fichiers à la racine du dépôt GitHub, branche `main`, puis activer GitHub Pages dans Settings > Pages > Deploy from a branch > main > /(root).

## Installation sur Android
Ouvrir l'adresse GitHub Pages dans Chrome, puis menu ⋮ > Installer l'application (ou Ajouter à l'écran d'accueil).

## Données
Les données sont conservées localement dans le navigateur du téléphone. Elles ne sont pas synchronisées entre appareils. Utiliser l'export CSV pour conserver une copie de l'historique.
