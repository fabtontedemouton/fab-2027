FAB 2027 — PACK ANDROID

Ce pack contient le projet Android complet et les fichiers de l'application FAB 2027.
L'application fonctionne hors ligne : l'interface est embarquée dans l'APK et les saisies sont conservées localement sur le téléphone.

COMPILATION AUTOMATIQUE AVEC GITHUB
1. Décompressez ce ZIP.
2. Dans le dépôt fab-2027, téléversez le CONTENU du dossier FAB_2027_ANDROID à la racine du dépôt (pas le dossier parent).
3. Acceptez le commit.
4. Ouvrez Actions : le workflow « Build FAB 2027 Android APK » doit démarrer.
5. Quand l'exécution est verte, ouvrez-la et téléchargez l'artefact « FAB-2027-APK ».
6. Décompressez l'artefact et installez app-debug.apk sur le téléphone.

Le fichier APK généré est un APK de test (debug), pas une version signée pour le Play Store.
Pensez à exporter régulièrement vos données avec le menu de l'application.
